## HakurouPaper v0.8.1

本版本在 v0.8.0 基础上，完善 Markdown 文件打开、超链接和源文件行号体验，并保留已有的本地版本管理、Word 导出及后台运行优化。

### 更新内容

- **Markdown 源文件行号**：在编辑区左侧显示对应源文件的行号，可通过「查看 → 显示源文件行号」开启或隐藏，并自动记住设置。跨多行的内容显示起止行号，编辑后自动更新。
- **从 Windows 打开 Markdown**：支持通过右键「打开方式」使用 HakurouPaper 打开 `.md`、`.markdown`、`.mdx` 文件；程序已经运行时，新打开的文件会交给现有窗口处理。
- **超链接打开体验**：点击文稿中的网页链接时，使用系统默认浏览器打开；拖选链接文字不会误触发跳转。
- **外部修改检测**：文稿被其他程序修改后，无未保存编辑时自动更新；存在未保存编辑时提示比较、重新加载或另存副本，减少覆盖风险。
- **Word 表格导出优化**：按当前样式导出时，普通表格使用正文可用宽度；选择 Word 参考模板时保留模板控制。

### 安装与使用

- 当前提供 Windows x64 安装程序：`HakurouPaper_0.8.1_x64-setup.exe`。
- 安装后可在「查看 → 显示源文件行号」中体验新增功能。
- 常规 Word 导出仍需 Pandoc；MathType 转换仍需本机安装 Microsoft Word 和 MathType。
- 安装文件的 SHA-256 校验值见附件 `SHA256SUMS.txt`。
